> **课程来源**：FDE 实战训练营第一期 · 第 12 节
> **时长**：约 1 小时 43 分
> **核心问题**：几千块钱的单，怎样从问诊走到「连续三轮稳定」再结款？

本节目录：咨询三问 → 攀岩馆三档报价 → 交付全流程 → 飞书标注 → 统领 Skill → 工具链 → 风控 → 验收与作业。

周末两天线下收到反馈：实操还要再多。于是这周提前把模拟实战拉到线上，用脱敏案例拆完整流程。沟通课、以及「会 vibe coding 但怎样把它做稳」的工程加餐，后面用录播、群里回放补，不再占直播。第二期当时计划 9 月上线平台，第一期学员用兑换码看回放。

第一期天使学员的福利（以当时公告为准）：线上录播一年回看，后面各期精选会变成加餐；一年内线下再复训一次，场地限制每次大约不超过 10 人，要排队。人才库在收，群里要填。手头项目大约 9 月能谈下一批，进项目建群交付，要求会比上课严格得多。

直播先告一段落：今天到周五共四期，之后看时间再安排一次集中答疑（当时估计放到下周，给没跟上的课和没交的作业）。今天千元档，明天万元档，逐步更复杂。

千元档卖的不是「一个大模型账号」，而是一条**能周更的内容生产线**。生成「好看帖子」的具体配方课上不讲：

> 至于怎么样生成这些好看的帖子，那就是我们的商业机密了……知道 OK 有这么一个事情就可以了。

学员要建立的判断是：这件事成立，且能用 AKA 装起来。

## 一、先当商业医生，再报价

千元档按流程第一步是**咨询诊断**。商业医生做两件事：问诊（到底有什么问题）、开药方（怎么解决）。几千块搭一套知识库和工作流，并不需要很高的技术水平，但三个问题必须问清：

1. **为什么想做**：智能体也好，工作流也好，要解决什么问题
2. **想达到什么效果**：这就是验收标准，回款时要对上
3. **预算范围**：3000 有 3000 的做法，5000 有 5000 的做法，8000 有 8000 的做法

方案报价用**三档报价法**：基础版、标准版、旗舰套餐，让客户选。千元档的售前方案只讲三件事就够：**能提供什么、大概怎么实现、展示 demo**。不必搞复杂。售前方案的细讲放到沟通课录播。

给客户算账，比讲模型有用。招一个稍好的小红书运营，按 1 万成本算（到手八千多，公司还要交社保），一年十万起。这个人的职责大致是：拍摄、写文案、发布。拍摄可用 AI 生图；文案可打磨一套营销文案 Skill；人一天 3～5 条已经不错，AI 做到二三十条质量还能看，理论上 100 条则大半是垃圾，不建议。

## 二、脱敏案例：杭州攀岩馆

客户是线下攀岩馆，要用小红书做门店和业务的同城曝光、获客。

当时诉求：替代小红书运营，**每天至少 10 条**（原来的人一天一两条）。对流量和获客要求不高——要求很高也不会是这个价格。初步预算 3～5 千。

能提供什么（简略版；更完整应带过往案例）：

- 知识库梳理搭建：他已有图片素材就接着整理；若要从零梳理，价格要往上走到万元档
- AI 生图工作流
- 营销文案 Skill
- 自动排版保存的工作流

怎么实现：资料收集 → 员工访谈、看有没有 SOP → 从生图到文案到发布全流程做成 Skill → 展示 demo。这种简单项目**纯线上就能搞定**，不必去现场；万元起的单子才谈驻场。约饭、咖啡馆碰一下可以。

三档当时是这样切的：

| 档位 | 给什么 | 老师怎么算 |
| --- | --- | --- |
| 3000 | 只做一套 AIGC 生图工作流，辅助现有运营出图 | 雇人 3K 也要这个数；运营月薪六千里约一半是拍摄制作 |
| 5000 | 生图 + 营销文案 | 一个下午能出图，两天能把图+文做像样 |
| 8000 | 生图 + 文案 + 自动发布整条 | 客户按「约等于这个员工一个月工资」选了 8K |

报价周期要**故意拉长**：生图工作流一天甚至一个下午能做完，图+文顶多两天；当时对客户说大约 **3 周**，实际大约一周。周期说太短，后面价格不好往上要。客户选了 8K。

## 三、完整交付流（千元档不必做重）

```
咨询三问 → 三档报价 + 售前三件事 + demo
  → 客户电脑装 WorkBuddy、开通 DeepSeek API（客户自己充）
  → 装 CDP、小红书 Bridge，授权飞书
  → 扒矩阵号 / 竞对 / 同行爆款，飞书云文档做数据标注
  → 三个 Skill（生图、文案、草稿箱）+ 一个统领 Skill
  → 连续三轮稳定测试 → 交回电脑 → 7 天售后 + SOP / 说明书
```

测试 3～10 轮都可以，以稳定为准。客户体验有问题就改，确认后验收结款。千元档不要做成中台。

Token 钱老师不赚：在客户电脑本地跑，让客户去 DeepSeek 开放平台实名、充值、把 API key 配进 WorkBuddy，滑到最底下选自定义模型。WorkBuddy 个人会员不建议个人充，企业版另说。每一步截图写进飞书云文档 SOP，下次他自己照着做。有人问「步骤能不能做完就删、不告诉客户」——想加价理论上可以；这对朋友介绍的千元档客户，老师选择做成完整 SOP 交给对方，8000 打完单子结束。

## 四、知识库：飞书云文档上的数据标注

客户有小红书矩阵账号（课上不展示具体主页）。搭建逻辑：

1. 把自己账号主页的图和帖扒一遍
2. 竞对里数据较好的图和帖也扒
3. 同行业爆款的图、文案一并进库
4. 再单独做一份**爆款文案知识库**，热度高的文案抽出来做成 Skill

需要三套库：**图片、文案、同行参考**。千元档三个 Skill 就能打住：生图（把 AIGC 工作流融进去）、文案、发布。

标注不要只丢给 AI 摘要。AI 全自动提取也能做，但往往是 **60 分**；要七八十分，得用人在飞书云文档里写评论。飞书评论的好处是：评论钉在具体段落上，模型能读，等于在做数据标注。至少认真标 **20～30 篇**。

一篇帖子建议拆成这些块（标题分级要有层级，模型才知道归属）：

| 板块 | 标什么 |
| --- | --- |
| 帖子链接 | 网页地址 |
| 帖子数据 | 点赞、收藏、评论（转发在前台看不到） |
| 封面图 / 文中图 | 小红书封面单独是一门讲究，不要和图集合并 |
| 标题、正文、标签 | 三块文案元素；正文要分行分点，口语、像分享种草 |
| 飞书评论 | 每一块好在哪、为什么有量 |
| 评论区详情 | 另建多维表格子表：评论者、点赞、回复数、评论 ID、正文 |

课上用杭州攀岩馆热帖举例，只讲**标注思路**，不讲生成配方。例如某篇收藏高，是因为它把多家场馆的适合人群、体验课、分店线路、时间距离地铁口写清楚；另一篇标题带情绪和地名，首图字号大、排版工整、图上全是字。你要标的是结构、信息增量和风格，不是把「怎样一键出爆款图」写成可复制配方。

抽奖帖、种草合集帖，好的原因不同，文案 Skill 里要按类型分开看。评论区能看到真实问题（新手有没有绳、哪条线路简单、去了某馆感觉很难），这些是内容增量，也有风控风险，平台规则在升级，过一段时间就要换方法。

给模型下抓取指令时，老师先自己标一篇当**上下文范例**，再要求：

- 已装 CDP，能控 Chrome；已装 XHS Bridge，能进小红书后台
- 浏览器里已登录账号，搜「杭州攀岩馆」
- 筛选热门，并分别按点赞最多、收藏最多、评论最多各取 TOP 10
- 按范例整理：链接、三维数据、封面 / 其他图、标题 / 正文 / 标签
- 每一块加飞书评论：好在哪、不好在哪、为什么有量
- 每个帖子一张评论区子表
- 抓取时不规律间隔，避免风控
- 整理完形成三套 Skill，再收成统领 Skill

视频同理，课上只给链路、不给成片配方：下载视频 → 转音频 → 转文字（提到 FFmpeg、Whisper 一类工具和 TTS），再按同样方式标注，可生成脚本方向的 Skill。

## 五、三个 Skill，加一个「小领导」

有了标注，剩下可以交给 AI 收成知识库和 Skill。三个分 Skill：

1. **图片制作**：这个领域什么样的图更容易有流量（从帖子和评论区反推，不写具体画风秘方）
2. **文案撰写**：种草合集、活动抽奖等类型各自好在哪；标题 / 正文 / 标签分开；正文口语、小红书分享感
3. **保存到小红书草稿箱**：登录后由 Bridge 操控后台

再做一个**统领 Skill**（例如「攀岩馆小红书制作」），把上面三个收成子目录。以后只对统领说话，它按「先图、再文、再存草稿」派活。不必从机制上「听懂」它怎么调用——就这样下指令即可。

评论区问「总管 Skill 怎么调用其余几个」。老师的说法是：你不必从机制上听懂。

> 你创建一个总的这个 Skill。你就是这个团队的小领导，然后前面三个 Skill 都是你的部门的小员工……第一步派做图片的，第二步派写文案的，第三步把图片和文案排版好，保存到草稿箱。

为什么拆开：图不好只调图片 Skill，文案不好只调文案 Skill；揉在一个大 Skill 里，改一处可能改坏别处。草稿箱步骤是**通用**的，下一次做健身馆、游泳馆，图片和文案风格换掉，草稿箱可以共用。不拆开也可以，模型自己会在一个 Skill 里分三步，但你必须把三步说清，否则它不会想到要存进你的草稿箱。

课上顺手用「水彩工程速写」一类画风 Skill 出过精华面膜图文，再经 Bridge 存进草稿箱——这是在演示**调用链已经通了**，不是把该画风当成可对外交付的生成配方。封面、三张图、标题、文案、标签齐了，人只需要点发布；老师刻意停在暂存。CDP 加 Bridge，本质是**模拟人手点后台**，不是 WorkBuddy 和平台之间另有一条官方传输通道。

总控一次指令的产品形态，就是客户要的：「我给产品图 / 场馆素材，你稳定出帖」。不是再听一遍提示词课。

## 六、工具链：在客户电脑上接通，不讲生成配方

中间默认步骤：客户电脑装 WorkBuddy，开 DeepSeek API。然后：

- **CDP**（课上装的是偏热门的 CDP Bridge MCP）：授权本地 Chrome，让模型操控浏览器。Chrome 扩展：开发者模式 → 加载已解压的扩展；路径常在隐藏的 `.workbuddy/tools/...` 下，Mac 可用 Shift+Command+句号显示隐藏文件夹，有时要再点进一层才是真正的扩展目录
- **小红书 Bridge / XHS Bridge Skill**：登录账号后操控小红书后台
- **飞书连接器 / CLI**：把整理结果写进云文档和多维表格
- **火山引擎**：推荐给客户做 AIGC，因为上面模型多（DeepSeek、智谱、豆包等）。视觉侧课上点名 **Seedream 5.0 Pro** 生图、**Seedance** 做视频（当时最新视频模型提到 Seedance 2.5）。开通 API 后，用生图 Skill 调模型，来回看效果、给修改意见

发布 Skill 老师打包好了，学员不必追究后台点击细节；装好 Bridge、登录即可。搜索、筛选「最多点赞 / 最多收藏」可以人做，也可以交给已授权的 AI。

知识库可以搭在飞书上，用豆包工作伙伴（老师提到它不再叫旧名字）或 WorkBuddy 调用。本地 WorkBuddy 老师觉得更顺。模型本身吃过大量小红书语料，提示里写「小红书风格」往往就能像；**没有标注，文案不是不能写，是没味道**。行业 knowhow 在标注，不在流水线骨架。

> 真正拉开差距的地方不在于这一套流程……真正的地方在于你这个标注。

## 七、风控是这个档位的命门

小红书对账号、操作节奏敏感。方案里必须写清：哪些步骤能自动，哪些必须人手点。

课上踩过和强调过的点：

- **不要自动点发布**。模型可以一路点到「发布笔记」，但自动发布容易触发风控。正确收口是**暂存离开 → 进草稿箱 → 人在手机上点发布**。需要的话再规定：点原创声明、选合集、定时发布；不行就停在草稿
- **抓取不要机械间隔**。不要每两秒点开一张图。课上要求不规律：2 秒、3 秒、5 秒，像人点帖。Skill 里内置随机抖动（有时 2 秒、有时 3.5 / 4.2 / 5 秒）
- **连续抓六篇必须冷却**；固定间隔必触发风控
- 用浏览器筛选、制作，老师当时主号还没遇到风控，但**建议小号操作**；大不了申诉是他的风险偏好，不能写进对客户的默认方案
- 搜索返回 0、提示触发风控时，先看后台和账号，不要加码硬刷
- 平台风控会升级，方法隔一段时间要重找

只追求产量、不管风控，交付当天好看，第二周账号没了。账号矩阵怎么隔离、标题和素材如何避免模板脸，都要在方案里写，但具体「如何生成不像模板的图」仍属于课上不公开的配方，笔记只保留判断标准：交付必须含风控，而不是含一套可复制的作图秘方。

## 八、验收、售后、可以卖到哪

成果不是再演示一遍提示词，而是：知识库 + Skill **安装在客户电脑**，配置好，**连续三轮稳定**——第一轮出问题不算，修到连续三遍不出问题再交电脑。之后 **7 天售后**：连不上就远程。提到的远程工具：网易 UU 远程（双方登同一账号）、ToDesk、向日葵，各有槽点，备三个。另交 Skill 使用说明书 + 发布操作 SOP。3 月那单还在云端 Open Cloud 上做过，并用 Seedance 做过视频发布；自动发帖教程有，但单价不高就没做全自动。客户愿意出 2 万、3 万，才谈到生图生视频都更自动。

熟练的人一晚上能搭出骨架，对客户仍说至少一周，再留测试和反馈。8K 打到账，是这个档位的正常收口。口条好、能讲清价值，同一套理论上可以卖到约 2 万；**卖 8 万客户会回来找你**——客户不是傻子。课上有人提预装进 iPad 或腾讯云 + Hermes 当 SaaS 卖，老师说可以，那是进阶封装，不是千元档必做项。和官方合作、完善成可推流的产品，是另一条生意：一家商家哪怕卖 1 万，卖 1000 家就是 1000 万。课上说思路简单，难点仍是行业 knowhow——知识库的梳理、搭建、标注。没有标注，AI 写文案不是不能写，是没味道。

也可以先封装成网页应用（课上有过 Run studio 一类 demo：表单填完出图文笔记）。进阶是塞进 iPad 或云服务器当 SaaS。那是后话，不是 8K 必选项。

## 九、作业（三选一）

选一个方向，做一套小红书全流程内容制作（知识库 + Skill）：

1. 杭州攀岩馆（任选一家）
2. 杭州健身馆（课上点名乐刻、超级猩猩；游泳馆课上测过容易出不宜内容，不作为作业）
3. 自由方向；全自动发布也可以换城市

提交两样：知识库 + Skill 的压缩包；**你自己的思考和思路**（可以让 AI 辅助，但建议人写）。只丢飞书文档让 AI 执行、自己说不清怎么做，过不了「知识的诅咒」这一关。

## 十、这节课里点过的坑

- 从零梳理知识库还按三五千报价，活已经是万元档
- 生图一个下午能做完，报价周期却说成「两天交付」，后面不好加价
- 只让 AI 自己摘要爆款，标注这一步省掉，内容停在 60 分、没味道
- 封面图和文中图混成一栏，标题 / 正文 / 标签揉成一段
- 三个 Skill 写成一个大文件，改图伤到文案，草稿箱也无法复用到健身馆
- 让模型自动点「发布」，或固定每两秒抓一页——风控比产量来得快
- 连续抓六篇不冷却；搜索已经返回 0 还加码硬刷
- 把「好看帖子怎么生成」写成对外配方；课上的边界是：知道这件事成立，配方不讲
