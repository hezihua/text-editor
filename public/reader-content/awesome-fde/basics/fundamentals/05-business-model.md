> **时长**：约 1 小时 23 分
> **定位**：基础课收束前的商业基本功，用来给客户做诊断

> **先抓主线**：商业模式不是一句“用 AI 降本增效”，而是把一笔生意从头到尾说清楚：客户为什么付钱、你卖什么、如何获客和成交、怎样交付、成本与回款如何安排、客户是否会复购。诊断企业的 AI 机会，也要放回这条赚钱路径里看。

## 第一部分：先看懂一门生意怎么赚钱

## 一、商业模式就是赚钱的路子

不要先背渠道、框架名词。一句话拉齐定义：

> 所谓商业模式，其实就是赚钱的路子，就是你怎么赚钱。

三个环节：

| 环节 | 核心任务 |
| --- | --- |
| **获客** | 找到**有预算**的客户 |
| **销转** | 签单 + 收款 |
| **交付** | 用产品或服务把价值交出去 |

没有水源，后面的模式都是空转。钱像水：有水才有生机，有钱才有商机；荒漠没水就很难有生命。2026 年 B 端注意力和预算聚集在「AI 落地解决方案」，这就是当前水源。先找到水，才谈得上搭一整套赚钱模式。

## 二、挖水井、铺水管、收水费

找到水源之后，模式通常走三步。改良自师爷润宇（前老板的创业导师，浙大创业班，商业博主）的「建房子 / 铺水管 / 收水费」：

这三个比喻可以理解成商业化的成熟顺序：先用服务亲自解决问题，确认客户真的愿意付钱；再把重复部分标准化，降低每次交付成本；最后才考虑订阅、按量收费等持续收入。不要在需求还没验证时就先投入做 SaaS 或软硬件产品。

```
找到水源
   →  挖水井（用时间脑力体力服务，验证需求）
   →  铺水管（标准化成课程、SaaS、软硬件套件）
   →  收水费（订阅、Token、按人头、年框）
```

| 阶段 | 含义 | 累在哪 | FDE 例子 |
| --- | --- | --- | --- |
| **挖水井** | 吭哧吭哧给人服务，一点一点打水 | 人的时间有上限，一天满负荷 12、14 小时不持久；又懂业务又懂技术的人难筛 | 培训 + 定制（最高频的两种服务） |
| **铺水管** | 把验证过的服务标准化，可复制 | 标品单价往往更低，但能批量 | 标准化课件；做成小程序 / App；Mac mini 软硬件封装 |
| **收水费** | 水管铺好后持续收费 | 要先把管铺出去 | Token 中转；WorkBuddy / 飞书按人头订阅 |

直播课是挖井；录播再卖是铺管；会员和 Token 是收水费。

### 挖水井也有门道：培训怎么分层

同样叫「企业 AI 内训」，课上拆成四种，对应不同阶段、不同有水的位置——不是往下傻挖 10 万米。

1. **老板高管闭门会**：认知拉齐，看 2026 年 AI 长什么样、对公司意味着什么。后面可接 **CEO 陪跑 / 老板个人提效**——老板时间是公司里最贵的，解放注意力和判断就是公司提效
2. **全员入门 / 理论课**：很多人真没装过 WorkBuddy、没体验过 Codex。要让他感到「动动嘴就能让 AI 操控电脑、搭库、做工作流」。滨江、上城一些团委课请「专家」讲得云里雾里，反衬出基础普及仍有需求。入门课要讲得好，不能水
3. **实战带练（今年新做）**：开课前先问卷 + 高管 / 业务负责人不超过半小时访谈，再按部门需求定制案例。2～3 天，带着问题和电脑来，手把手从零搓知识库和 Skill
4. **项目制培训**：给大型集团、500 强、上市公司。纯咨询很虚——广东食品集团一个单品做到 5 个亿，花 80 万请有点名气的咨询公司，一点用没有。客户不再为纯课买单，要员工学会并用到日常。周期拉到约两个月：线下一天 + 线上两小时答疑交叉；第一个月筛出各部门 **AI 先锋 / AI 苗子**，避免 IT 十几人扛全公司（上一节那个上市公司）。星星之火，能力长在客户身上

很多人学会了仍没时间把 60 分搓到 90 分——来回标注「这样对、那样不对」很痛苦。所以 **智能体定制** 才成立：背后仍是知识库 + Skill。自己能搞，就不会找你花钱。

标准化之后可以拆讲师：入门课给入门讲师，定制课给高级讲师，定制 + 带练给顶级讲师。软件化是另一条水管。再往上，软硬件打包：知识库、工作流、UI 都装进一台机器，客户点一点。定制一台 Mac mini，少说 5～10 万；有渠道的骚操作，年框小培训 + 小定制 + 运维，一台能卖 **20 万**。

收水费：WorkBuddy 企业版课上印象是约 **316 元 / 人 / 月**，同时收 Token 和订阅；飞书商业专业版 / 标准版一个人一年也可能要小 1000。年框、月费保证固定回款，偏订阅，严格说不完全等于「躺着收水费」。

FDE 的难题仍是重人力、难复制。把人铺进去就要面对管理小团队、筛复合型人才。水管和水费是在井验证过之后，才有资格谈的。

## 三、看懂一家公司的七个问题

给企业做落地前，至少问清这七问。课上用「老板买 AI 线下课」把答案走一遍：

| # | 问题 | 线下课例子 |
| --- | --- | --- |
| 1 | **谁来付钱 / 钱从哪来** | 老板付钱 |
| 2 | **为什么付钱** | 想学知识、操作、方法论 |
| 3 | **卖的是什么** | 线下大课（产品还是服务要说清） |
| 4 | **怎么收钱** | 一次性对公打款（也可以是订阅、项目分成） |
| 5 | **怎么交付** | 集中 2～3 天上课 |
| 6 | **利润在哪一段最厚** | 人大老远来听两天，觉得值；签协议后课已交付，至少值 5000，想退也不能全退 |
| 7 | **怎么持续赚钱** | 7980 的课讲完推 39800 升单；或卖龙虾军团一类 SaaS 订阅 |

所有公司都建立在「怎么赚钱」上，才会从 OPC → 小团队 / 个体户 → 有部门的中小公司 → 抖音、字节那种平台。老板关心两件事：能不能多赚钱，能不能持续赚钱。

## 四、赚钱是一个循环，断一环就消亡

用「FDE 靠自媒体赚钱」把循环走一遍：

```
客户从哪来（自媒体）
  → 为什么下单（卖点、案例、身份背书，让他相信你）
  → 买的是什么（服务还是产品）
  → 怎么交付（驻场培训、定制、应用、工作流、知识库）
  → 什么时候回款（预付 / 月度 / 尾款）
  → 怎么复购（升单、转介绍、订阅、运维；或不做复购、持续浅服务获客）
```

| 断在哪 | 后果 |
| --- | --- |
| 不会获客，没渠道、没关系、没内容 | 从一开始就没水 |
| 客户只打探、不下单 | 后面都不成立 |
| 下了单不交付 | 空手套白狼，下一单做不成 |
| 交付了收回不了款 | 纠纷和恶运，团队开支扛不住 |
| 既无复购、又无持续获客 | 一次性生意，模式消亡 |

> 所有的商业模式都建立在一个逻辑上，就是人心的洞察。你如何去获取他的信任。

回款分三块：**预付款**（没服务可退，服务了扣一笔）、**阶段性回款**（每月一笔）、**尾款**。FDE 重人力，这两种最能保现金流：先收预付，或按月 / 年框订阅。整项目做完再催，风险极大。

## 五、算账：老板至少看三本账

算账是指挥公司活下去。不管会计怎么做，老板关心三本：

三本账回答的是不同问题：**利润账**看这笔生意最终赚不赚钱，**现金账**看钱什么时候进出、公司能不能撑到回款，**单位经济账**看某条产品线或单个项目复制得越多究竟是赚还是亏。收入高不代表利润高，利润为正也不代表现金流安全。

### 1. 利润账（一层层扣）

```
营收
- 直接成本（投流、营销、商务、销售；B 端还可能含大额渠道分钱）
= 毛利
- 经营成本（工资、财务、公关、法务、经营风险）
= 经营利润
- 税、折旧、损失
= 净利润
```

不是进账 1000 万就是纯利。

### 2. 现金账

收入看起来很多，支出也很多，仍会入不敷出。最伤现金流的是**垫款**和**回款账期**。预付 + 订阅，是 FDE 活下去的两种水。

### 3. 单位经济账（单条产品线的 ROI）

只算总账会养亏损业务。课上用乐华举例：王一博一年至少赚几个亿，养底下亏钱的小明星，一场线下活动 100 多万——钱全是头部赚来的。每条产品线、每个客户项目都要单独算投入产出。

投资人和大佬常问壁垒、护城河。课上判断：市面上多数公司答不上来，最大的壁垒往往是**执行力**——

1. 别人没干，你干了（3 月装龙虾，别人嘲讽 500、1000 块割韭菜，老板一点不犹豫；20 分钟一套脚本）
2. 别人也干，你更快（5 月发《2026 年中国 FDE 人才白皮书》，官方推 FDE 后还有国家智库和地方领导来要源文件）
3. 一样快，你质量更好（不用土 FDE 的苦路 vlog 堆人设，用方法论、逻辑、案例）
4. 一样好，你成本更低、利润更高（供应链、AI 技术、管理出 SOP）
5. 最后拼现金流、拼谁活得更久（前老板做头部公众号，2018 年起家，一篇 28 万广告、约一个字一千多；2020 年品牌方手里至少 50 个百万博主账号，2024 年可能只剩 15 个——把对手熬死）

## 六、六种生意，十种收钱，六种利润来源

服务下来五花八门，按「卖的是什么」可收成六类：

| 生意 | 卖的是什么 |
| --- | --- |
| 实体商品 | 所有权（手机卖给你就属于你） |
| 虚拟物（SaaS、课、知识产权、付费内容、租房） | 使用权 / 复制权 |
| 服务 | 时间 + 结果（例如一小时 3000 的咨询 + 诊断报告） |
| 资产 / 租赁 / 金融 / 保险 | 钱的时间和风险 |
| 平台 / 渠道 / 博主广告 | 中介入口、流量 |
| 连锁 / 加盟 | 可复制的经营系统（蜜雪冰城：店长店员反复回总部培训、交作业、考试，供应链和 SKU 都管好，才不砸牌子） |

收钱方式课上数了约 10 种：一次性；项目分成；人天 / 人时（咨询一小时 3000、安装师傅、保洁）；订阅费（软件使用权）；会员费（圈子、身份、渠道，和订阅不是一回事）；佣金抽成（渠道费）；广告线索；利差 / 保费；许可 / 版权 / 租金；按量（Token API、水电煤、油）。

利润怎么变厚，六种来源：

1. **抬价**：品牌、个人品牌、能出结果的同行案例——展示稀缺性
2. **控成本**：实体靠供应链；技术革新（一天的活一小时）；管理（没 SOP、没制度，一群人混乱，成本就高）
3. **周转**：餐饮翻台率（海底捞一小时换桌 vs 两小时还在桌边打游戏）；库存（闲鱼先挂链接、有人买再进货）；资金流动（借出去尽快收回再借给下一个人）
4. **规模**：先标准化再复制，边际成本下降
5. **差价**：时间差、信息差、汇率差、地域差，倒买倒卖
6. **流量入口**：渠道、博主、平台

本质仍是人心和购买旅程：看到 → 了解 → 心动 → 冲动下单 → 觉得值或退款 → 复购 → 拉朋友转介绍。台价是让他更相信你；管理是管理人。现阶段钱在人手里不在 AI 手里。题外话：微信已给 AI 开银行卡，未来会有围绕 AI 代理支付的模式，但还不是主流。

## 第二部分：把商业理解用于 FDE 客户诊断

前半部分是在理解客户自己的生意；从这里开始，把前几节的市场、AKA、数据和组织知识串起来，判断 AI 应该解决哪一个经营问题。

## 七、串完五节，给客户做诊断的六步

FDE 要懂业务也要懂技术。懂业务，就是知道客户怎么赚钱、卡在哪，像商业医生先读懂人体的血脉骨骼。前面几节加上这一节，已经可以做一份不空的诊断：

六步是从经营结果往技术方案走：先看钱和账，再确认老板真正卡在哪里，接着拆到具体部门流程，最后才用 AKA 找切入口。顺序不要倒过来；如果一开始就推荐工具，容易把客户的问题误诊成“缺一个 AI”。

| 步 | 做什么 | 为了什么 |
| --- | --- | --- |
| 1 | 画**钱的流向图**：钱从哪来、怎么流转、成本和收益怎么分 | 看见水源和漏水处 |
| 2 | **账本分析**（能做最好做）：利润、现金、单位经济 | 很多老板自己也说不清哪里能上 AI；这步对应降本增效 |
| 3 | 问赚钱七问 | 对应营收增长：内部经营还是外部增长 |
| 4 | 问老板 / 高管：**经营瓶颈**到底是增长问题还是经营问题，最困难的是哪一段 | 避免你替他脑补需求 |
| 5 | 梳理部门流程：哪些费脑力、费时间 | 找到白领可改的卡点 |
| 6 | 用 **AKA** 对卡点：装 Agent、搭知识库、搓 Skill，必要时加定时任务 | 覆盖约 80%，结束 |

### 六步之外的课上补充（选型与报价口径）

当天在义乌见的头部饰品公司（耳环、项链、戒指，外贸）：海外客户发来三视图、五视图、平面或白板草图 → 厂里只有一两个作图师做 CAD 3D 建模 → 算尺寸、按金银铜材质算克重 → 报价 → 铜模 / 胶膜 → 批量。流水线本身 AI 改不动。卡点是**活多人少**：需求来了要排期，客户要约 45 天交付，海外客户回消息可能再吃掉 10 天。老板满负荷还能扛住 45 天，不愿多招人，只想更快。切入点：接 API，搓 CAD Skill，加快出图，而不是重建工厂。

四五线城市同样逻辑：看有没有白领脑力工作。线下门店可以做内容工厂、客户档案、地推目标清单和谈客方案。客户愿不愿出钱，看账算不算得过来——花 50 万，至少要能省回或赚回 50～100 万；平账当试验，有人也接受。理论上，账能算过来，预算可以没有上限。

RAG 当卖点？文档不多不必真上 RAG，本地 Obsidian 或飞书就够，也可以「包装成 RAG」；文档极大（义乌童装 ERP 里十几万张图要向量化）才谈自研，成本很高。传统人力密集、对硬件感兴趣的国网类甲方，一体机的精准用户就是国央企，可筛可信厂商合作，不一定是 Mac mini。

WorkBuddy 用着别扭：课上承认它没有很强，国内只是没有更好的，希望字节和阿里再出竞品。Claude Code 仍是开发第一，尤其 Fabric 5 + Claude Code；其次 Codex + GPT 5.6。国外工具要过网络、封号、数据安全。Codex 里「通过屏幕上下文增强记忆」一类开关会后台截屏，课上建议关掉；真要防，就物理隔离——一台专用海外 AI，一台工作机。沙箱是君子协议。

## 八、和前面几节怎么串

- 第 1 节：市场水源在不在，窗口和两类意志
- 第 2 节：交付物是 AKA，不是某一个模型
- 第 3 节：K 决定你能不能稳定交付
- 第 4 节：拍板人和组织决定你能不能成交、能不能推行
- 第 5 节：商业模式决定方案打在哪一段价值链上——挖井、铺管还是收水费，内部经营还是外部增长

串完这五节，已经可以做一份不空的 AI 改造诊断提纲。**还差第 6 节法律合规底线**（哪些活不接）；六节都过完，基础课才收束。之后进技术课，才上手一步步实操。

## 九、踩坑

- 先背商业模式画布，不先找有预算的水源
- 井还没出水，就投入做 SaaS、一体机
- 只卖 80 万咨询方案，不保证学会、用上（食品集团的课上反例）
- 培训不分层，用同一套理论课打老板、全员和业务骨干
- 整项目做完再收款，利润账好看、现金账把人拖死
- 只算总账，亏损产品线被头部项目养着
- 制造业卡在作图师排期，却去承诺改造产线
- 文档很少还强卖自研 RAG；或者把飞书直接转手，客户何必经过你
- 四五线开口就「FDE 能不能落地」，不先问对方是门店、小公司还是部门

- [ ] 判断自己和客户分别处在挖水井、铺水管还是收水费，下一步只推进一步
- [ ] 按七个问题把一家目标公司填满，空着的格子就是访谈清单
- [ ] 画出这条生意的赚钱循环，标出最容易断的一环
- [ ] 给自己的项目列三本账：净利润怎么扣、回款账期几天、单条产品线 ROI
- [ ] 对照六种生意和十种收费，写出你现在卖的是所有权、服务还是订阅
- [ ] 按六步给一个真实客户做诊断：流向图 → 账 → 七问 → 瓶颈 → 流程 → AKA 切口
- [ ] 检查交付合同：预付、月度回款、尾款是否写清，有没有把风险留到项目结束

下一节是**法律合规底线**：技术上能做、生意上不接的口径写死。六节串完，再谈技术课动手与实战案例里的售前 / 执行方案拆分。
