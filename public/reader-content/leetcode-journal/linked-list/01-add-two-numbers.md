## 题意

给你两个**非空**的链表，表示两个非负整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例 1：**

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807
```

**示例 2：**

```
输入：l1 = [0], l2 = [0]
输出：[0]
```

**示例 3：**

```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```

**约束：**

- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 思路

模拟**竖式加法**过程：

1. 使用哑节点统一处理结果链表头节点。
2. 同时遍历两条链表，把对应位相加，并加上进位 `carry`。
3. 当前位结果 = `sum % 10`，新进位 = `sum / 10`。
4. 循环条件：只要还有节点没处理完，**或者还有进位**，就继续。
5. 最后返回哑节点的下一个节点。

关键点：进位可能让结果多出一位，必须处理到最后。

## 代码

```go
func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
    dummy := &ListNode{}
    curr := dummy
    carry := 0

    for l1 != nil || l2 != nil || carry > 0 {
        sum := carry
        if l1 != nil {
            sum += l1.Val
            l1 = l1.Next
        }
        if l2 != nil {
            sum += l2.Val
            l2 = l2.Next
        }
        carry = sum / 10
        curr.Next = &ListNode{Val: sum % 10}
        curr = curr.Next
    }
    return dummy.Next
}
```

|------|--------|

| 空间 | $O(\max(m, n))$（结果链表长度） |
