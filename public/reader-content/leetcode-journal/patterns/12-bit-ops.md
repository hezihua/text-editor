## 什么时候用

和「出现一次 / 两次」、子集、开关、棋盘状态有关，或要把 $n \le 20$ 的集合压进整数。

## 常用式子

| 操作 | 写法 | 含义 |
|------|------|------|
| 判断第 $i$ 位 | `x>>i & 1` | 是否为 1 |
| 置 1 / 清 0 | `x \| (1<<i)` / `x &^ (1<<i)` | 开、关 |
| 去掉最低 1 | `x & (x-1)` | Brian Kernighan 数 1 |
| 只留最低 1 | `x & -x` | 树状数组也用 |
| 模 2 幂 | `x & (n-1)` | $n$ 是 2 的幂时 |
| 交换 | `a, b = a^b, a^b, a^b` | 不推荐，可读性差 |

```go
func hammingWeight(n uint32) int {
    c := 0
    for n != 0 {
        n &= n - 1
        c++
    }
    return c
}
```

## 只出现一次

其余都出现两次：全部异或，成对的消掉，剩下就是答案。出现三次要用两位状态机，或统计每位 1 的个数模 3。

## 子集枚举

$n \le 20$ 时，用 `0..(1<<n)-1` 表示选或不选。

```go
func subsets(nums []int) [][]int {
    n := len(nums)
    ans := make([][]int, 0, 1<<n)
    for mask := 0; mask < 1<<n; mask++ {
        var cur []int
        for i, x := range nums {
            if mask>>i&1 == 1 {
                cur = append(cur, x)
            }
        }
        ans = append(ans, cur)
    }
    return ans
}
```

旅行商、棋盘覆盖、状压 DP 都是这个编码。和回溯比：无需递归，但 $n$ 不能大。

## 注意

- 算术右移和逻辑右移：符号位，Go 的 `>>` 对有符号是算术移位
- `1<<31` 在 32 位有符号会溢出，用 `1<<uint(i)` 或 `1 << i` 注意类型
- 异或交换写不清楚就用临时变量
