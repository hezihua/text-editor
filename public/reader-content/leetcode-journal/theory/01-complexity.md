## 在算什么

复杂度不关心「这台机器跑了几毫秒」，只关心输入规模 $n$ 变大时，时间和额外空间怎么涨。大 $O$ 丢掉常数和低次项，只留增长最快的那一项。

$$
O(1) \subset O(\log n) \subset O(n) \subset O(n\log n) \subset O(n^2) \subset O(2^n)
$$

同一段代码，最好、平均、最坏可能不一样。快排平均 $O(n\log n)$，枢轴总选最偏时最坏 $O(n^2)$。题目约束通常按最坏或期望来卡。

## 怎么读一段代码

先数循环层数，再看每层里有没有「看起来 $O(1)$、其实是 $O(n)$」的操作。

```go
// 看起来一层循环，其实每次 insert(0) 都是 O(n)
for i := 0; i < n; i++ {
    a = append([]int{i}, a...)
}
```

这段是 $O(n^2)$。数组中间插入、字符串反复拼接、在循环里对有序切片做 `insert`，都是这类陷阱。

递归不要只看「写了几层函数」，要看递归树有多少节点、每层做多少功。斐波那契朴素递归树接近 $O(2^n)$，加记忆化后每个 $n$ 只算一次，变成 $O(n)$。

## 常见量级和约束

| 复杂度 | 大约能扛的 $n$ | 典型来源 |
|--------|----------------|----------|
| $O(1)$ | — | 下标、哈希均摊 |
| $O(\log n)$ | $10^{18}$ 也能二分 | 二分、平衡树高 |
| $O(n)$ | $10^7$ 量级 | 单次扫描 |
| $O(n\log n)$ | $10^5$ | 排序、堆、归并 |
| $O(n^2)$ | $10^3$ | 双层枚举 |
| $O(2^n)$ | $20$ 上下 | 子集、未记忆化回溯 |

LeetCode 常见 $n \le 10^5$，基本只能 $O(n)$ 或 $O(n\log n)$。先写暴力复杂度，超了再换结构。

## 空间

输出数组一般不计。递归栈要计，深度 $h$ 就是 $O(h)$。滚动变量、双指针常把 $O(n)$ 压到 $O(1)$。

哈希表、集合按最坏占 $O(n)$。原地算法（轮转、矩阵置零）是用输入或输出本身当工作区。

## 用在题上

1. 先估暴力，对一下约束。
2. 要下标 → 哈希；要有序 → 排序或二分；要区间和 → 前缀。
3. 能滚动就别开整张表。
