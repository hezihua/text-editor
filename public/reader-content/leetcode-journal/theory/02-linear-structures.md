## 数组

连续内存，按下标读写 $O(1)$。中间插入、删除要搬后面的元素，是 $O(n)$。动态切片扩容单次可能 $O(n)$，均摊仍是 $O(1)$。

适合做：下标映射、双指针、前缀和 / 前缀积、滑动窗口、原地交换。

前缀积把「除自己以外」拆成左右两段，见 [238](/topics/array/product-of-array-except-self)。区间合并是先排序再扫一遍，见 [56](/topics/array/merge-intervals)。

## 链表

节点散落，靠指针串。头插、在已知节点后插入是 $O(1)$，按下标找是 $O(n)$。单向链表没有前驱，删除当前节点通常要停在前一个。

刷题三板斧：

- **哑节点**：统一「头节点被删 / 被换」的情况
- **快慢指针**：中点、环、倒数第 $k$ 个
- **翻转**：先存 `next`，再改 `curr.Next`

```go
func reverse(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    for curr != nil {
        next := curr.Next
        curr.Next = prev
        prev = curr
        curr = next
    }
    return prev
}
```

[19 删倒数第 n 个](/topics/linked-list/remove-nth-node-from-end) 快指针先走 $n+1$ 步；[25 K 组翻转](/topics/linked-list/reverse-nodes-in-k-group) 先数够不够 $k$ 个再翻。

## 栈

后进先出。括号匹配、表达式、递归改迭代、单调栈都靠它。

单调栈存「还没找到下一个更大 / 更小」的下标，每个元素进出各一次，总时间 $O(n)$。直方图最大矩形、每日温度是同一套路。

## 队列

先进先出。层序遍历、无权 BFS、滑动窗口里的单调队列。双端队列两端都能弹，适合维护窗口最值。

## 怎么选

| 需求 | 优先 | 本站例子 |
|------|------|----------|
| 按下标读写 | 数组 | 两数之和、轮转 |
| 改指针、头插 | 链表 | 两数相加、两两交换 |
| 最近相关性 / 回溯 | 栈 | 递归改写、括号 |
| 按到达顺序 / 按层 | 队列 | 层序、BFS |

线性结构决定遍历顺序。顺序一换，后面的树、图、排序写法就不一样。
