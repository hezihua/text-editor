## 图怎么走

**BFS**：队列，按层扩展。无权最短路、层序、距离。每个点入队一次，时间 $O(V+E)$。

**DFS**：递归或栈，走到底再回头。连通性、网格染色、拓扑前的访问。

表示：稀疏用邻接表，稠密或 $O(1)$ 问边用邻接矩阵。网格把四向当隐式图，不必先建表。

还要会：入度表拓扑排序、并查集聚类、Dijkstra 处理正权最短路。有负权边且没有负环用 Bellman-Ford；有负环要先检测。

先问清四件事：有向还是无向、有没有权、要路径还是只要可达、有没有环。

## 动态规划四步

1. **状态**：$f(i)$ 表示什么（以 $i$ 结尾、前 $i$ 个、容量 $j$）
2. **转移**：从哪些更小的状态来
3. **边界**：$f(0)$、空、第一个元素
4. **目标**：通常是 $f(n)$ 或所有 $f(i)$ 的最大 / 最小

```go
// 爬楼梯
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }
    a, b := 1, 2
    for i := 3; i <= n; i++ {
        a, b = b, a+b
    }
    return b
}
```

[53 最大子数组和](/topics/array/maximum-subarray)：$f(i)=\max(a[i],\ f(i-1)+a[i])$，滚动一个变量即可。

能画出转移箭头，再写循环顺序——必须先算出被依赖的状态。一维常可滚动到 $O(1)$ 空间。

## 模板对照

| 类型 | 状态直觉 | 注意 |
|------|----------|------|
| 线性 DP | 走到第 $i$ 个 | 以 $i$ 结尾还是前 $i$ 个 |
| 背包 | 容量 / 选没选第 $i$ 件 | 0-1 倒序滚，完全背包正序 |
| 区间 DP | $[l,r]$ 上的最优 | 按长度从小到大 |
| 树形 DP | 以 $u$ 为根的子树 | 后序保证子先算完 |

## 和图的交界

DAG 上的路径计数、最短路，既可以 BFS/DFS，也可以按拓扑当 DP。有环就不能直接递推，要先消环或改成最短路算法。

网格最短路往往 BFS 就够；要计数或带障碍的方案数，更像 DP。先定「这是在走路还是在记账」，再选结构。
