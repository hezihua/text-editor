## 比较排序的下限

基于比较的排序，最坏至少 $\Omega(n\log n)$：决策树有 $n!$ 片叶子，高度至少 $\log(n!)$。所以快排、归并、堆排是主菜；$O(n^2)$ 的插入、冒泡用来理解稳定性。

## 三张主牌

**快排**：选枢轴，小的左大的右，两边递归。平均 $O(n\log n)$，原地、不稳定。随机枢轴或三数取中避免最坏。分区写成：

```go
func partition(a []int, l, r int) int {
    pivot := a[r]
    i := l
    for j := l; j < r; j++ {
        if a[j] < pivot {
            a[i], a[j] = a[j], a[i]
            i++
        }
    }
    a[i], a[r] = a[r], a[i]
    return i
}
```

第 K 大用同一套分区即可，平均 $O(n)$，不必全排。

**归并**：先拆后合，稳定，$O(n\log n)$，额外 $O(n)$。链表归并不用数组，见合并两条有序链再推广到 K 路。

**堆排**：建堆 $O(n)$，弹出 $n$ 次堆顶。思想和优先队列一样。

稳定：相等元素相对顺序不变。插入、归并稳定；快排、堆排一般不稳定。要「先按一键再按另一键」，用稳定排序叠起来。

值域小可用计数 / 基数，接近 $O(n+k)$，受空间限制。

刷题：区间合并、三数之和都是先排序再线性扫。

## 二分：循环不变量

选定区间后，循环里始终保证「若答案存在，一定还在区间内」。

闭区间 $[L,R]$：循环 `L <= R`，`a[mid] < x` 则 `L = mid+1`，大于则 `R = mid-1`。

半开 `[L,R)`：循环 `L < R`，右边界更新是 `R = mid`。**两套不要混。**

```go
func lowerBound(a []int, x int) int {
    l, r := 0, len(a)
    for l < r {
        mid := l + (r-l)/2
        if a[mid] < x {
            l = mid + 1
        } else {
            r = mid
        }
    }
    return l
}
```

三种问法：是否存在（704）、下界 / 上界（34、35）、在**值域**上二分答案（check 单调）。旋转数组、峰值是分段单调，先判断 `mid` 落在哪一段。

`mid` 写成 `L + (R-L)/2`。收缩漏 `±1` 会死循环。
